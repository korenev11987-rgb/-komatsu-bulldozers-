# Бульдозеры Komatsu: интерактивные схемы

Интерактивные SVG-схемы (вид сбоку) бульдозеров **Komatsu D155AX-8, D355A-3 и D475A-8**
на Vite + React + TypeScript.

- 25 кликабельных узлов в пяти системах: мотор, ходовая, трансмиссия, гидравлика, электрика;
  фильтр по системам, панель с описанием, выноски-подписи, управление с клавиатуры (Tab, Enter / Пробел).
- Классическая жёлтая окраска, внутренние узлы показаны «рентгеном» в окнах разреза.
- Пропорции машин рассчитаны по паспортным габаритам (длина, высота по кабине, отвал,
  база гусеницы, клиренс, рыхлитель). Цифры и ссылки на источники приведены в `src/data/d155.ts`,
  `src/data/d355.ts`, `src/data/d475.ts`; оценочные значения помечены как приблизительные.
- Панель «Как работает»: этапы «Запуск двигателя», «Подъём и опускание отвала», «Рыхление»,
  «Движение с набором грунта»; кнопки воспроизведения и паузы, переход между этапами, «Все этапы».
  При системной настройке «уменьшить движение» этапы показываются ключевыми кадрами.

Ссылки на состояние: `?model=D475&node=engine`, кадр анимации: `?model=D155&anim=rip&t=0.5`.

## Запуск

Нужен Node.js 18+ (рекомендуется 20).

```bash
npm ci          # или npm install
npm run dev     # http://localhost:5173
npm run build   # сборка в dist/
npm run preview # просмотр собранной версии
```

## Публикация на GitHub Pages

В репозитории настроен workflow `.github/workflows/deploy.yml`. Он запускается
при push в ветку `main` или вручную (вкладка Actions, затем «Run workflow»).

1. Создайте репозиторий на GitHub и отправьте код:
   ```bash
   git remote add origin https://github.com/<пользователь>/<репозиторий>.git
   git push -u origin main
   ```
2. В репозитории откройте **Settings → Pages → Build and deployment** и в поле **Source** выберите **GitHub Actions**.
3. После завершения workflow сайт будет доступен по адресу
   `https://<пользователь>.github.io/<репозиторий>/`.

Workflow собирает проект с `VITE_BASE=/<репозиторий>/`. Если переменная не задана,
сборка использует относительный путь `./`. Тогда содержимое `dist/` можно открыть с любого
статического хостинга или из любой папки.

```bash
VITE_BASE=/komatsu-bulldozers/ npm run build   # как на GitHub Pages
```
